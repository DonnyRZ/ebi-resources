# EBI RESOURCES

### Tujuan Bisnis

Website EBI Resources berfungsi sebagai website resmi holding untuk:

* Memperkenalkan EBI Resources dan seluruh bidang usahanya
* Menyatukan portofolio bisnis dalam satu website
* Meningkatkan kredibilitas perusahaan
* Mendukung peluang kerja sama bisnis
* Mempermudah publik memperoleh informasi resmi
* Mendukung kebutuhan rekrutmen grup
